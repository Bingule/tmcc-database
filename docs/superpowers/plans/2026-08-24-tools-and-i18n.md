# Bilingual Materials Research Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add English/Simplified Chinese localization and four standalone, browser-local research-tool routes without changing TMCC database data or unrelated behavior.

**Architecture:** A small typed translation context and pathname route selector wrap a shared site shell. Pure TypeScript chemistry, regression, CV parsing, interpolation, analysis, and export modules remain independent from localized React pages. Existing inline-SVG conventions are extended through one focused scientific chart component, and a post-build route copier makes direct GitHub Pages URLs work.

**Tech Stack:** React 19, TypeScript 5.7, Vite 5, Vitest/jsdom, Lucide React, CSS, `read-excel-file@9.3.10`.

## Global Constraints

- Work only on branch `add-tools`; never merge automatically.
- Preserve all existing routes, homepage sections, TMCC records, filtering, charts, and query/hash behavior.
- Add only one primary-navigation discovery item: Tools.
- English is the default; only explicit `en`/`zh` selection persisted as `tmcc-language` may override it.
- Do not translate formulas, element symbols, material IDs, space groups, numeric values, file names, equations, or units.
- Keep all scientific processing in the browser; do not add a backend or external data transmission.
- Do not smooth data; do not extrapolate beyond the common overlapping potential domain.
- Use `|i|` for b-value logarithms; skip zeros and return no fit when fewer than two valid rates remain.
- Implement b-value fitting exactly as `log(|i|) = log(a) + b log(v)` and recover synthetic `b = 0.5` and `b = 1.0` cases.
- Use signed Dunn reconstruction but magnitude-based trapezoidal integration for percentages; normalize capacitive and diffusion percentages to 100%.
- Implement Dunn fitting exactly as `i(V) / sqrt(v) = k1 sqrt(v) + k2`, with `i_cap = k1 v` and `i_diff = k2 sqrt(v)`.
- Implement theoretical capacity exactly as `Q = nF / (3.6M)` with `F = 96485.33212 C/mol` and `Q` reported in mAh/g.
- Version 1 supports CSV/TXT/XLSX import, CSV result export, and SVG/PNG figure export.
- Version 1 does not include paste-from-Excel, smoothing, insertion-mode electron inference, or XLSX result export.
- Every new behavior follows a red-green-refactor test cycle; never write production logic before observing its test fail for the expected reason.
