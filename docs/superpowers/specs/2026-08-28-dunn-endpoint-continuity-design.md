# Dunn 端点连续与无回钩重建设计

## 目标

保证 Dunn 电容贡献在原始 CV 的完整电位范围内连续显示，尤其避免转折点附近因分支归属和显示抽样而出现提前终止、长直线连接或无有效面积的视觉塌缩。

## 已确认约束

- 保持 `i_cap,f(V) = g(V) * i_f(V)` 与 `i_cap,r(V) = g(V) * i_r(V)` 不变。
- 保持一个共享且满足 `0 <= g(V) <= 1` 的 `g(V)`。
- 不旋转曲线、不移动电位坐标、不对两条电容电流分支独立平滑。
- 在局部 CV 包络于真实转折点收缩为单点时，最终共享 `g(V)` 必须使两条电容边界精确回到该物理可行端点；对 NCP 的同号转折电流，这等价于端点 `g(V) = 1`。
- 不删除越界点；继续使用现有软包络重建。
- 转折点裁剪只影响 Dunn 拟合，不缩短最终重建、绘图、积分或导出范围。
- 单次记录的转折点是相邻两条分支的共享显示端点；双次记录且电流不同的转折点继续分别保留，不平均。
- 准确转折点处面积可以自然趋近于零，但端点附近不得因显示抽样而形成多点零宽度或长直线桥接。
- 若原始正扫或反扫分支在端点邻域内保持单调，最终电容边界不得产生原始分支中不存在的新局部极值或斜率反转。

## 根因

完整 `plotPath` 已按原始扫描顺序保存所有测量点，核心重建也在完整公共网格上计算。然而：

1. 单次记录的转折点在 `plotPath` 中只拥有一个分支标签，`makeBranchBoundaryPoints` 因此只把它加入一条电容虚线，另一条虚线从相邻采样点开始。
2. `sampleDunnPlotPath` 强制保留每个分支的首尾点，但未强制保留首尾附近的连续点。数据量超过图形点数上限时，端点和下一个保留点之间可能形成比原始网格更长的直线段。
3. 现有软包络优化明确跳过公共电位网格的首尾点，并用额外保真权重把端点保持在原始 `g(V)` 附近。显示层补齐端点电位后，端点电流仍为 `g(V) * i_raw(V)`；当转折点处的局部包络宽度为零且 `g(V) < 1` 时，电容边界必然落在 CV 包络外。
4. 现有页面测试只验证两条虚线合并后覆盖完整横坐标范围，没有验证端点电流与物理转折点重合，也没有验证端点邻域无交叉和连续性。
5. 当前修正用固定 5% smoothstep 在软包络优化完成后把 `g(V)` 拉向端点 `g(V) = 1`。虽然 `g(V)` 本身连续且端点斜率为零，但乘积 `g(V) * i_raw(V)` 的斜率仍可能反号。NCP 50 mV/s 的原始右端分支没有斜率反转，而修正后的上侧电容边界在最后 5% 电位范围内出现了多个很小的新局部极值，形成可见回钩。

## 方案比较

### A. 共享 `g(V)` 的端点约束正则化（采用）

- 在分支切换处，将单次记录的真实转折点作为相邻两条电容边界的共享显示点。
- 由首尾两支原始电流求共享 `g(V)` 的端点可行区间，并把端点可行值作为同一次正则化优化的等式约束；NCP 两端的可行解为 `g(V) = 1`。
- 删除优化后的固定 smoothstep 事后重连。端点过渡由现有保真项、归一化二阶平滑项和包络项共同确定，使曲率分布在优化中自然协调。
- 从端点向内识别原始分支连续且方向稳定的单调尾段。仅在这些尾段加入线性形态约束：`g(V) * i_raw(V)` 的相邻差分不得与对应原始分支方向相反，数值容差内的平坦段允许保留。
- 正扫和反扫的形态约束共同作用于同一个 `g(V)`。当两支约束同时存在时联合求解；`g(V) = 1` 等同原始 CV，因此物理上始终存在满足约束的可行解。
- 同一个最终 `g(V)` 继续同时生成正、反两条电容分支；绘图、积分和导出都使用这一个结果。
- 抽样时保留每个分支首尾各 8 个连续记录，再在剩余点中执行现有确定性抽样。
- 优点：同时满足完整电位范围、端点物理包络、连续形态和共享比例约束，并从根源上避免固定过渡函数与原始电流相乘后产生回钩。

### B. 更换或加宽 smoothstep（不采用）

- 使用五阶 smootherstep，或把固定重连范围从 5% 扩大。
- 缺点：只能改变回钩的位置或幅度，不能保证乘积 `g(V) * i_raw(V)` 保持原始分支的单调方向。

### C. 独立平滑电容电流边界（不采用）

- 分别对正、反两条 `i_cap(V)` 曲线做单调平滑。
- 缺点：会破坏一个共享 `g(V)` 的核心物理约束，并可能让绘图、积分和导出失去同源性。

## 数据流

1. 软包络优化先产生现有正则化共享比例 `g0(V)`。
2. 端点形态分析器在归一化公共电位网格上计算端点可行比例，并分别识别正、反分支的稳定单调尾段；近零差分使用尺度相关容差，不把测量噪声误判为物理转折。
3. 共享优化器以 `g0(V)` 为保真基线，同时施加 `0 <= g(V) <= 1`、端点等式、二阶平滑、软包络和稳定尾段方向约束，直接输出最终共享 `g(V)`。
4. 优化后验证器统计端点误差、包络残差和相对于原始分支新增的局部极值。任何超过容差的新增回钩都视为重建失败，不把异常结果交给绘图或导出。
5. `analyzeCvWorkflow` 用最终 `g(V)` 产生完整 `DunnContribution`，因此绘图、面积、贡献率和 CSV 导出保持同源。
6. `sampleDunnPlotPath` 锁定分支首尾及其 8 点邻域，再执行现有确定性抽样。
7. `makeBranchBoundaryPoints` 在真实分支切换位置共享转折记录，使相邻虚线在同一电位和同一电流自然衔接。

## 验证

- 页面回归测试：单次记录转折点必须同时出现在相邻两条电容虚线中。
- 重建单元测试：同号收缩包络的首尾端点必须精确可行；端点约束必须在正则化求解内满足，不再依赖固定 smoothstep 后处理。
- 形态单元测试：原始端点尾段单调时，两条最终电容边界不得新增方向反转；原始尾段确有局部极值时必须保留，不得强行单调化。
- 抽样单元测试：每个分支首尾各 8 个原始连续点必须保留。
- NCP 回归：每个扫描速率保持完整电位范围、有限结果、共享 `g(V)`、符号和幅值约束；50 与 2 mV/s 的精确端点与原始转折点重合且无尖尾、回钩或断裂。NCP 50 mV/s 右端原始单调尾段的新增斜率反转计数必须为零。共享正比例不得新增分支交叉；原始 CV 自带的亚像素交叉必须保留。
- 记录端点重连前后的贡献率差异；允许由最终同源重建产生的小幅、可审计变化。
- 执行完整测试、TypeScript 检查和生产构建。
