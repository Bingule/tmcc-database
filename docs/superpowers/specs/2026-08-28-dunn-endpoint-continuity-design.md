# Dunn 端点连续显示设计

## 目标

保证 Dunn 电容贡献在原始 CV 的完整电位范围内连续显示，尤其避免转折点附近因分支归属和显示抽样而出现提前终止、长直线连接或无有效面积的视觉塌缩。

## 已确认约束

- 保持 `i_cap,f(V) = g(V) * i_f(V)` 与 `i_cap,r(V) = g(V) * i_r(V)` 不变。
- 保持一个共享且满足 `0 <= g(V) <= 1` 的 `g(V)`。
- 不旋转曲线、不移动电位坐标、不对两条电容电流分支独立平滑。
- 在局部 CV 包络于真实转折点收缩为单点时，最终共享 `g(V)` 必须使两条电容边界精确回到该物理可行端点；对 NCP 的同号转折电流，这等价于端点 `g(V) = 1`。
- 不删除越界点；继续使用现有软包络重建。
- 转折点裁剪只影响 Dunn 拟合，不缩短最终重建、绘图、积分或导出范围。
- 单次记录的转折点是相邻两条分支的共享显示端点；双次记录且电流不同的转折点继续分别保留，不平均。
- 准确转折点处面积可以自然趋近于零，但端点附近不得因显示抽样而形成多点零宽度或长直线桥接。

## 根因

完整 `plotPath` 已按原始扫描顺序保存所有测量点，核心重建也在完整公共网格上计算。然而：

1. 单次记录的转折点在 `plotPath` 中只拥有一个分支标签，`makeBranchBoundaryPoints` 因此只把它加入一条电容虚线，另一条虚线从相邻采样点开始。
2. `sampleDunnPlotPath` 强制保留每个分支的首尾点，但未强制保留首尾附近的连续点。数据量超过图形点数上限时，端点和下一个保留点之间可能形成比原始网格更长的直线段。
3. 现有软包络优化明确跳过公共电位网格的首尾点，并用额外保真权重把端点保持在原始 `g(V)` 附近。显示层补齐端点电位后，端点电流仍为 `g(V) * i_raw(V)`；当转折点处的局部包络宽度为零且 `g(V) < 1` 时，电容边界必然落在 CV 包络外。
4. 现有页面测试只验证两条虚线合并后覆盖完整横坐标范围，没有验证端点电流与物理转折点重合，也没有验证端点邻域无交叉和连续性。

## 方案比较

### A. 共享 `g(V)` 的平滑端点重连（采用）

- 在分支切换处，将单次记录的真实转折点作为相邻两条电容边界的共享显示点。
- 由首尾两支原始电流求共享 `g(V)` 的端点可行区间，并把最终端点投影到该区间；NCP 两端的可行解为 `g(V) = 1`。
- 在归一化电位坐标的首尾 5% 范围内，用两端一阶导数为零的 smoothstep 权重把端点修正平滑衰减回原软包络解。
- 同一个最终 `g(V)` 继续同时生成正、反两条电容分支；绘图、积分和导出都使用这一个结果。
- 抽样时保留每个分支首尾各 8 个连续记录，再在剩余点中执行现有确定性抽样。
- 优点：同时满足完整电位范围、端点物理包络、连续形态和共享比例约束；不会形成单点硬折线。

### B. 增加端点优化惩罚（不采用）

- 在共享 `g(V)` 优化中增加端点斜率或非零面积惩罚。
- 缺点：有限惩罚不能保证收缩包络端点精确可行，也不能单独修复虚线分支缺失共享端点这一绘图拓扑问题。

### C. 只把最后一个显示点硬贴到原始边界（不采用）

- 只在绘图层替换最后一个电流值，或几何旋转电容曲线。
- 缺点：会造成尖角/长直线，并让绘图、积分和导出使用不同数据。

## 数据流

1. 软包络优化先产生现有正则化共享比例 `g0(V)`。
2. 端点重连器在归一化电位上计算首尾平滑权重，将 `g0(V)` 最小幅度地过渡到端点可行比例，输出一个最终共享 `g(V)`。
3. `analyzeCvWorkflow` 用最终 `g(V)` 产生完整 `DunnContribution`，因此绘图、面积、贡献率和 CSV 导出保持同源。
4. `sampleDunnPlotPath` 锁定分支首尾及其 8 点邻域，再执行现有确定性抽样。
5. `makeBranchBoundaryPoints` 在真实分支切换位置共享转折记录，使相邻虚线在同一电位和同一电流自然衔接。

## 验证

- 页面回归测试：单次记录转折点必须同时出现在相邻两条电容虚线中。
- 重建单元测试：同号收缩包络的首尾端点必须精确可行；修正必须在归一化 5% 邻域内平滑衰减，邻域外保持原解。
- 抽样单元测试：每个分支首尾各 8 个原始连续点必须保留。
- NCP 回归：每个扫描速率保持完整电位范围、有限结果、共享 `g(V)`、符号和幅值约束；50 与 2 mV/s 两端无包络越界、交叉、尖尾或断裂。
- 记录端点重连前后的贡献率差异；允许由最终同源重建产生的小幅、可审计变化。
- 执行完整测试、TypeScript 检查和生产构建。

## 非目标

- 不修改 b 值分析。
- 不增加新控件或设置。
- 不重新设计页面布局。
- 不改变 CSV/XLSX/TXT 导入。
- 不合并 `main`。
