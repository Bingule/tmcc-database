# TMCCDB 2.1.0 Phonopy 上线设计

状态：待书面审阅。

目标：导入完整 P 相 Phonopy 结果，展示最低频率和可缩放的声子色散，更新筛选、列顺序、版本号及 Sofer 称谓；不提交计算、不覆盖原始结果。

数据：以材料 ID 逐项匹配 356 个机械稳定 P 相记录。347 个完整结果中，用全 q 网格最低频率及 −0.2 THz 容差判定动力学稳定；三个磁矩接近零而原 JSON 分类为空的完整结果依用户决定按频率分类并标注来源。9 个 SCF 未收敛项保持 Pending。期望汇总为 24 Stable、323 Unstable、9 Pending；导入时从源数据重新核算，不符则停止发布。Γ 单点不得用于完整动力学稳定性判定。

导入：新增幂等导入脚本，只改目标材料 JSON 的 phonons 字段，保留其他物性及 ID。存储 phonon_calculated、dynamically_stable、minimum_frequency_thz、容差、超胞、位移、电子设置、源路径和可得的作业 ID。检查力常数、全 q 频率与 band CSV 的存在和解析；缺失时不造数据。每个完整材料导出独立精简色散资源，保留路径段、距离、q 坐标、分支和 THz 频率，不平滑或插值。原始结果只读保留。

界面：页眉、页脚和项目版本更新为 2.1.0；Dr. Sofer 改为 Prof. Sofer，Dr. Wu 不变。Explorer 的相关列顺序为 Mech. Stab. → Min. Phonon Freq. (THz) → Dynamic Stab.，最低频率替换原表格 E_form 列；详情页形成能保留。频率数值排序，缺失显示 — 而非 0；稳定筛选需 phonon_calculated === true 且 dynamically_stable === true。已计算状态链接至 #phonon-properties。

详情：展示计算状态、稳定性、最低频率、−0.2 THz 容差、计算参数和来源。延迟加载单材料多分支声子谱，沿用现有图表的拖选、滚轮缩放及重置操作；标注高对称点和 THz 轴。缺失项只显示 Pending，不绘制假曲线。图为声子频散而非 Raman 强度。

验收：数据测试核对 356/347/9 和 24/323/9 汇总、三个例外、阈值边界、路径和重复导入；UI 测试核对列顺序、排序、筛选、锚点和缩放。运行仓库数据校验、测试与构建。仅选择性提交本任务文件，经 GitHub Pages 工作流部署 main，核查 tmccdb.org 的版本、表格、筛选及代表性详情；失败则诊断，不宣称上线成功。不得带入现有无关工作区改动。

边界：动力学稳定性不等于机械或热力学稳定性；实验合成不代替全 q 判据；近零磁矩样本的声子分类不代表磁态收敛。
