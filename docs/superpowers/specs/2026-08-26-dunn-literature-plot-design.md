# Dunn 文献式贡献图设计规格

日期：2026-08-26  
范围：仅修改 `/tools/cv-kinetics` 的 Dunn 主图及其相邻说明，不改变导入、拟合、积分、表格或导出公式。

## 背景与根因

当前 Dunn 主图同时绘制原始 CV、重构总电流、电容贡献和扩散贡献四条折线。启用逐点 `R² ≥ 0.95` 后，低质量拟合会转为 `null`，因此真实 NCP 数据中只有 261 / 3413 个位置可绘制，贡献线呈现为零散短段。这在数值上遵守了筛选规则，但不符合文献中常见的“完整 CV 外轮廓 + 贡献填色”表达，也没有在主图附近充分揭示低覆盖率。

## 已确认的视觉与科学语义

1. 原始测量 CV 以完整、连续的带符号回线作为唯一主轮廓，继续保留文件顺序、正扫、回扫和转折点。
2. 对每个通过 R² 阈值的分析位置：
   - 电容区域绘制在零电流基线与 `k₁v` 之间；
   - 扩散区域绘制在 `k₁v` 与拟合总电流 `k₁v + k₂√v` 之间。
3. 不把拟合总电流强行裁剪到原始电流，也不把拟合残差归入任一贡献。若模型与测量不吻合，原始轮廓和填色边界的差异应保持可见。
4. 低于 R² 阈值、数据不足或拟合失败的位置不生成有效贡献填色，继续从百分比、结果表和 CSV 导出中排除。对应分析区间以中性灰色斜线区域表示“已排除”，区域边界采用该扫描速率的插值输入电流，只提供循环上下文，不表示有效 Dunn 分解。
5. 不跨越 `null` 间隙连接填色多边形；每个连续区段及每个扫描分支独立成形，避免跨转折点或无效区间造出假面积。
6. 在所选扫描速率控件与主图之间显示双语覆盖率提示：有效点数、取样点数和百分比。图形导出的 SVG/PNG 同时包含该覆盖率元数据。
7. 主图图例只保留：原始 CV 曲线、电容贡献、扩散控制贡献、低于质量阈值／不可用。原有重构总电流及两条贡献虚线不再出现在主图；其数值仍保留在结果表和现有 CSV 中。

## 组件设计

扩展现有 `ScientificLineChart`，增加可选的通用面积带数据，而不是创建一套重复坐标轴：

- 每个面积带点包含 `x`、`lower`、`upper`；任一边界为 `null` 即形成间隙。
- 面积带支持纯色透明填充和斜线图案两种样式。
- 面积带先于折线渲染，原始 CV 轮廓始终位于最上层。
- 图例用色块或斜线色块表示面积带；现有折线图调用不受影响。
- y 轴范围同时考虑折线与面积带的上下边界。
- 路径按输入顺序构造，允许完整 CV 回线的 x 值先增后减。

CV 页面负责把既有 `analysisGrid`、Dunn 状态和所选扫描速率映射为三个面积带；科学计算库不新增公式或状态。

## 响应式与无障碍

- 沿用现有 SVG `viewBox` 和移动端缩放行为。
- SVG `<title>`、`<desc>`、图例及覆盖率文字继续双语，并明确斜线区域是排除数据。
- 斜线区域不能只靠颜色表达；图例文字和图案共同区分。
- 不增加动画或新依赖。

## 测试与验收

1. 通用图表能按输入顺序生成面积带，遇到 `null` 和分支边界时断开，并在折线下方渲染。
2. Dunn 页面只显示完整原始 CV 折线，不再显示三条旧分量折线。
3. 有效位置生成电容和扩散填色；低 R²／不可用位置生成灰色斜线区域，且不会进入有效贡献面积。
4. 覆盖率提示在英文和简体中文下正确显示，并随阈值或数据变化更新。
5. 表格、六个 CSV、R² 排除规则、贡献百分比和完整循环顺序保持不变。
6. 真实 `NCP-CV——1.csv` 与 `NCP-CV——1.xlsx` 均可运行；默认 `R² ≥ 0.95` 时页面明确显示约 7.65% 有效覆盖率，并输出完整原始回线与分段填色。
7. 全量测试、TypeScript 检查和生产构建通过。
